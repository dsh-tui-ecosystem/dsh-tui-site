安装

          
    
            
  1. 解压 deepy-whale-theme.zip，得到顶层带 theme.json 的 deepy-whale/ 文件夹。
    2. 
            
  2. 放进 Clawd 的用户主题目录：
    
              Windows %APPDATA%/clawd-on-desk/themes/
    
              macOS ~/Library/Application Support/clawd-on-desk/themes/
    
              Linux ~/.config/clawd-on-desk/themes/
    3. 
            
  3. 打开 Settings… → Theme，选择 Deepy 小鲸鱼。列表里没有的话重启一次 Clawd。
    4. 
            
  4. 想让它跟着 DeepSeek 动，可以在 Settings… → Agents 里接入 DeepSeek Harness（实验性集成）。
    5.

$ node scripts/validate-theme.js deepy-whale
[Schema]        ✓ 12 项
[Eye Tracking]  ✓ idle-follow.svg 含 #eyes-js
[Assets]        ✓ 21 个引用文件全部存在
[Capabilities]  idleMode: tracked · sleepMode: direct
All checks passed! Theme "Deepy 小鲸鱼" is ready.

          
另外用 Clawd 自己的 theme-loader 严格模式加载过一遍，SVG 过安全清洗后内容没有任何改动，CSS 呼吸、眨眼、摆尾动画都保留。

        

        

          
暂未支持

          
Mini 模式（需要再画 8 个 mini 状态）、头饰/嘴部配件目录。睡眠用 direct 模式：60 秒无操作直接睡，被鼠标吵醒时播放惊醒动画。
