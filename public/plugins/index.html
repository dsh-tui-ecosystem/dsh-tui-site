两条路，殊途同归：列表数据就是一份 plugins.json，作者对自己的仓库拥有完全所有权，收录只做链接与背书。提交后自动校验 + AI 审查，通过即上架。

📋 收录要求4 checks

  • 仓库必须是公开的 GitHub 仓库，且提交者必须是仓库的 owner 或 collaborator
  • 仓库 README 必须包含 dsh-TUI 链接（https://dshtui.com 或 https://github.com/ccch1mneyyy/dsh-TUI）
  • 插件必须是 dsh-TUI / DeepSeek Harness 的真实扩展（主题、技能、状态栏、工具、Agent 等），AI 会结合描述与 README 判断
  • 通过后自动写入收录列表、立即上架；不通过会直接告诉你原因，改好重新提交即可（同一 IP 每 6 小时最多 10 次）
